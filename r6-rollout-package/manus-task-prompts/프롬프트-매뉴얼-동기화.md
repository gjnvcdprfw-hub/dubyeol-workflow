# 마누스 task 프롬프트 — r6 매뉴얼·양식 16개 silkroadhub 로컬 적용

> 이 문서는 [Owner]가 마누스에게 전달하는 task 프롬프트.
> 두별 워크플로우 v3.6.0 r1 베타 가동 *직전* 단계 — 매뉴얼 본체 동기화.
> 두별 워크트리 카테고리: **4 (문서·운영)**
> Tier: **A** (운영 문서 일괄 갱신 — 모든 향후 task의 기반)
> 진행 순서: 본 task가 *베타 가동 1순위*. 다른 마누스 task (CLAUDE.md 갱신, 스킬 GitHub 등록, scripts/ 작성)와 *병행 가능*하나, 본 task 완료 전에는 r6 매뉴얼 기반 task 진행 금지.

---

## task 개요

**목표**: 임시 컨설턴트 클로드가 제 컨테이너에서 작성·정정한 *r6 매뉴얼·양식 16개*를 silkroadhub 저장소의 옛 파일들과 비교 → 교체 적용 → [Owner] 승인 후 commit.

**배경**:
- 임시 컨설턴트가 SUB-1·SUB-2·SUB-3·SUB-5·AGENTS.md·마누스 프로젝트 지침·양식 4개에 *검증 발견 3가지*를 반영하고, *코덱스/지피티 역할 분리*·*plan-review 신설*·*스킬 호출 안내*까지 박은 *최종본*을 보유.
- silkroadhub 로컬에는 *옛 버전*(v3.5.0 또는 v3.6.0 초기본)이 그대로 있을 가능성 높음.
- 두 버전 간 *큰 차이*가 있을 수 있어 *diff 점검 후 교체*가 정확한 진행.

**핵심 안전선**:
- 운영 문서 변경 = **Tier A** 처리 의무. *task-card 생성* + *handoff 작성* 필수.
- 마누스 *임의 수정 금지*. 임시 컨설턴트 산출물을 *그대로 적용*. 차이가 있어 보이면 [Owner] 보고 후 결정.
- 자동 commit 절대 금지. diff·교체 후 [Owner] 검토 → 명시 승인 → commit (push는 또 별도 승인).

## Step 2 — 파일별 diff 점검

각 파일에 대해 `diff` 실행. 큰 차이를 *전부 보고*.

### 2.1 silkroadhub 백업

```bash
BACKUP_DIR=".harness/runs/${RUN_ID}/before-backup"
mkdir -p ${BACKUP_DIR}
cp AGENTS.md PROJECT.md SUB-1-기획의도.md SUB-2-워크플로우.md SUB-3-외부감리.md SUB-4-수정.md SUB-5-종료.md ${BACKUP_DIR}/
mkdir -p ${BACKUP_DIR}/.harness/templates
cp .harness/templates/*.md ${BACKUP_DIR}/.harness/templates/

ls -la ${BACKUP_DIR}/
```

### 2.2 12개 파일 diff 실행

```bash
DIFF_REPORT=".harness/runs/${RUN_ID}/diff-report.md"
echo "# r6 매뉴얼·양식 동기화 — diff 보고서" > ${DIFF_REPORT}
echo "" >> ${DIFF_REPORT}
echo "**run_id**: ${RUN_ID}" >> ${DIFF_REPORT}
echo "**비교 대상**: silkroadhub 로컬 vs 임시 컨설턴트 r6 산출물" >> ${DIFF_REPORT}
echo "" >> ${DIFF_REPORT}

for FILE in AGENTS.md SUB-1-기획의도.md SUB-2-워크플로우.md SUB-3-외부감리.md SUB-4-수정.md SUB-5-종료.md; do
  echo "## ${FILE}" >> ${DIFF_REPORT}
  if [ -f "${FILE}" ] && [ -f "/tmp/r6-new/${FILE}" ]; then
    OLD_LINES=$(wc -l < "${FILE}")
    NEW_LINES=$(wc -l < "/tmp/r6-new/${FILE}")
    echo "- 옛 분량: ${OLD_LINES} 줄 / 새 분량: ${NEW_LINES} 줄" >> ${DIFF_REPORT}
    echo "- 변경 줄 수: $(diff "${FILE}" "/tmp/r6-new/${FILE}" | wc -l)" >> ${DIFF_REPORT}
    echo "" >> ${DIFF_REPORT}
    echo '```diff' >> ${DIFF_REPORT}
    diff -u "${FILE}" "/tmp/r6-new/${FILE}" | head -100 >> ${DIFF_REPORT}
    echo '```' >> ${DIFF_REPORT}
  else
    echo "- ⚠️ 한 쪽 파일 없음" >> ${DIFF_REPORT}
  fi
  echo "" >> ${DIFF_REPORT}
done

# .harness/templates/
for FILE in task-card-template.md handoff-template.md gate-review-template.md final-report-template.md; do
  echo "## .harness/templates/${FILE}" >> ${DIFF_REPORT}
  OLD_PATH=".harness/templates/${FILE}"
  NEW_PATH="/tmp/r6-new/${FILE}"
  if [ -f "${OLD_PATH}" ] && [ -f "${NEW_PATH}" ]; then
    echo "- 옛 분량: $(wc -l < "${OLD_PATH}") 줄 / 새 분량: $(wc -l < "${NEW_PATH}") 줄" >> ${DIFF_REPORT}
    echo "" >> ${DIFF_REPORT}
    echo '```diff' >> ${DIFF_REPORT}
    diff -u "${OLD_PATH}" "${NEW_PATH}" | head -100 >> ${DIFF_REPORT}
    echo '```' >> ${DIFF_REPORT}
  else
    echo "- ⚠️ 한 쪽 파일 없음" >> ${DIFF_REPORT}
  fi
  echo "" >> ${DIFF_REPORT}
done

# PROJECT.md (변경 없을 가능성)
echo "## PROJECT.md (참고용)" >> ${DIFF_REPORT}
if [ -f "PROJECT.md" ] && [ -f "/tmp/r6-new/PROJECT.md" ]; then
  CHANGES=$(diff "PROJECT.md" "/tmp/r6-new/PROJECT.md" | wc -l)
  if [ ${CHANGES} -eq 0 ]; then
    echo "- 변경 없음 (예상대로)" >> ${DIFF_REPORT}
  else
    echo "- ⚠️ ${CHANGES} 줄 변경 발견. [Owner] 보고 필요" >> ${DIFF_REPORT}
    echo '```diff' >> ${DIFF_REPORT}
    diff -u "PROJECT.md" "/tmp/r6-new/PROJECT.md" >> ${DIFF_REPORT}
    echo '```' >> ${DIFF_REPORT}
  fi
fi

echo "" >> ${DIFF_REPORT}
echo "## 요약" >> ${DIFF_REPORT}
echo "- 변경 파일 수: <마누스 카운트>" >> ${DIFF_REPORT}
echo "- 신규 추가 절: <마누스 요약>" >> ${DIFF_REPORT}
echo "- 삭제된 절: <마누스 요약>" >> ${DIFF_REPORT}
echo "- [Owner] 검토 필요 영역: <마누스 짚을 점>" >> ${DIFF_REPORT}
```
