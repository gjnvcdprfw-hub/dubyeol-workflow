## SUB별 진입 첫 행동

각 SUB 로드 후 *반드시 인지해야 할 첫 행동*:

| SUB | 진입 첫 행동 |
|---|---|
| SUB-1 | §2 의도 정렬 5단계 SOP — [Owner] 발화 3중 재구성 시작 |
| SUB-2 | §1 진입 전 점검 → §2 [Builder] 진입 명령 전달 (스킬 03 호출) |
| SUB-3 | §1 정보 격리 원칙 재확인 → §3 [Reviewer] 호출 분기 판정 |
| SUB-4 | §1 SUB-4 진입 조건 점검 → §2 카테고리 분류 |
| SUB-5 | §1 종료 조건 충족 확인 → §2 final-report 작성 (스킬 08 호출) |

## 새 발화 패턴 발견 시

마누스가 [Owner] 발화에서 *위 표에 없는 새 라우팅 패턴*을 발견하면:
1. 그 자리에서 추론으로 적절한 매핑 시도
2. 추론한 매핑을 [Owner]께 *확인 후* 진행
3. final-report §12 회고에 *새 발화 패턴 발견* 기록
4. 다음 r 개정 시 본 표에 추가
