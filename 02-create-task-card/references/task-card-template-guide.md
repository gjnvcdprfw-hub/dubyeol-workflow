# task-card.md 양식 + 마누스 수동 보강 영역

본 문서는 `create_task_card.sh`가 자동 생성하는 task-card.md의 *각 절별 작성 기준*. 자동 생성 후 마누스가 *수동 보강해야 할 영역*도 명시.

## task-card 양식 — 10개 절

### §1 [Owner] 원 발화 (자동)
- `owner_utterance_file` 내용을 *원문 그대로* 박음
- 마누스 해석·번역·요약 *금지*. 원문 보존이 추적 가능성의 핵심

### §2 상위 맥락 연결 (수동 보강 ★)
- PROJECT.md §B 현재 분기 목표
- PROJECT.md §C.[N] 연결 모듈 — *N 식별이 마누스 판단*
- PROJECT.md §D 결정 이력 중 관련 항목
- *자동 추출 어려운 영역* — 마누스가 PROJECT.md 읽고 수동 작성

### §3 의도 정렬 증거 블록 (자동)
SUB-1 §2 SOP 5단계 결과 박힘:
- §3.1 한 문장 목표
- §3.2 Looks Like (3~5개)
- §3.3 Looks Wrong (3~5개)
- §3.4 모호어 스캔 결과
- §3.5 가정 (3개 이상)
- §3.6 [Owner] 정렬 확인 응답

### §4 Tier·카테고리·플랜 (자동)
- §4.1 Tier 판정 + 사유
- §4.2 두별 워크트리 카테고리 (1~5)
- §4.3 Gate 적용 여부 (Tier A/B는 gate-review.md 필수)

### §5 산출물 + 완료 기준 (수동 보강 ★)
- §5.1 산출 파일 목록 (구체 경로)
- §5.2 *제외 범위* (scope 밖) — 명시 의무
- §5.3 완료 기준 (검증 가능한 형태)
- *마누스 판단 영역* — 자동 생성 불가

### §6 진행 트리 (자동 + 변형 사유 수동)
- 카테고리별 표준 트리 자동 박음
- 변형 시 §6.1에 *변형 사유* 명시 (수동)

### §7 마스킹 적용 영역 (자동 + 수동)
- 기본 마스킹 패턴 (운송장·BL·개인통관고유부호 등) 자동
- 본 task 특화 마스킹 추가 영역 수동 보강

### §8 권한 천장·금지 사항 (자동 + 수동)
기본값 (자동):
- push/merge/deploy/force/reset --hard 금지
- 운영 문서 (AGENTS.md·CLAUDE.md·PROJECT.md·templates/) 변경 금지
- scope §5.2 침범 금지

본 task 특화 금지 (수동):
- 외부 시스템 실호출 제한 (해당 시)
- 특정 파일·디렉터리 보호 (해당 시)

### §9 변경 이력 (자동)
- task-card 자체의 수정 이력 추적
- 초안 작성 일시·작성자(마누스) 자동 박음

### §10 PROJECT.md 갱신 사항 (SUB-5에서 채움)
- §10.1 §C 모듈 진행 갱신 — *SUB-5 종료 시 작성*
- §10.2 §D 결정 이력 추가 — *task 진행 중 큰 결정 발생 시 작성*

## 마누스 수동 보강 체크리스트

자동 생성 후 마누스가 *반드시 점검·보강*:

- [ ] §2 PROJECT.md 모듈 §C.[N] 연결 식별
- [ ] §3.5 가정 *3개 이상* 확보 (부족하면 추가)
- [ ] §5.1 산출 파일 목록 *구체 경로* 박힘
- [ ] §5.2 제외 범위 명시 (scope 보호)
- [ ] §5.3 완료 기준이 *검증 가능*한지
- [ ] §6 진행 트리 카테고리 정합 (변형 시 §6.1 사유)
- [ ] §7 본 task 특화 마스킹 영역 추가
- [ ] §8 본 task 특화 금지 항목 추가

8개 모두 통과한 후에만 [Owner] 결재 요청.

## [Owner] 결재 양식

```
[Owner] 결재 요청 — task-card

run_id: <run_id>
Tier: <A/B/C>
카테고리: <1~5>
한 문장 목표: <§3.1 인용>

수동 보강 영역 점검 8개 항목 모두 통과.

승인하시면 SUB-2 진입 (스킬 03 dispatch-to-builder 호출).
거부하시면 §[어느 절] 정정 후 재제출.
```
