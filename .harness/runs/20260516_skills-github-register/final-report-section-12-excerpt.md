### 12.4 두별 워크트리 카테고리 조정 제안

본 task는 카테고리 4 문서·운영이 맞지만, “운영 인프라 공개 배포 + 마누스 자체 스킬 등록”은 일반 문서 작업보다 Blast Radius가 크다. r7에서는 카테고리 4 내부에 “운영 인프라 배포형” 하위 패턴을 만들고, GitHub 백업·스킬 직접 등록·공개 노출·도구 장애 대체 검증을 별도 체크리스트로 분리하는 것을 권고한다.
