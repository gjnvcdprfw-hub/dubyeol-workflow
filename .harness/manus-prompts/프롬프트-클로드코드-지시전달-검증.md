# 마누스 task 프롬프트 — 클로드코드 지시 전달 방식 검증

> 이 문서는 [Owner]가 마누스에게 전달하는 task 프롬프트.
> 두별 워크트리 카테고리: **4 (문서·운영)**
> Tier: **A** (모든 SUB-2 진입 명령 양식의 기반 — 본 검증이 안 되면 r6 운영 불가)
> 진행 순서: **r6 운영 시작 전 0순위**. 본 검증이 *최우선*. 통과 후 다른 검증·작성 task 진입.

---

## task 개요

**목표**: 마누스가 클로드코드(Claude Code, =[Builder]) 세션에 *지시를 전달*하는 두 가지 방식을 실제 환경에서 비교 검증. 권고 방식을 결정하여 AGENTS.md Appendix B *표준 절차*로 박음.

**배경**: r6 운영의 모든 출발점은 *마누스가 클로드코드한테 task-card 기반 진입 명령을 전달*하는 행위다. 이 행위가 안정적이지 않으면 *나머지 모든 것*(Codex 감리, ChatGPT 판정, handoff 검증)이 무의미. 두 방식이 알려져 있어 *어느 게 표준*인지 결정 필요.

**비교 대상 두 방식**:
- **방식 A**: `osascript do script`로 긴 텍스트 직접 입력 + 엔터
- **방식 B**: 파일에 지시 저장 후 *"이 파일 읽어서 진행해"* 짧은 명령만 전달

## Step 2 — 표준 테스트 지시문 작성 (두 방식 동일하게 사용)

같은 내용을 두 방식으로 보내야 *공정 비교*. 다음 내용을 *두 방식 다 사용*:

```
[테스트 지시문 — 두별 워크플로우 v3.6.0 r1 검증]

본 지시는 클로드코드 지시 전달 검증용이다. 다음 순서대로 응답하라.

1. 본 지시문의 첫 줄을 그대로 인용하라.
2. 다음 항목들을 그대로 옮겨 적어라:
   - 한글: "두별 워크플로우 v3.6.0 r1 베타"
   - 특수문자: $PATH, "double", 'single', `backtick`, \backslash
   - 줄바꿈: 본 항목이 *세 줄*에 걸쳐 있다는 사실
   - 들여쓰기: 본 항목은 2칸 들여쓰기로 시작한다
3. .harness/runs/test_claude_dispatch/result-METHOD.md 파일을 만들어 위 1~2번 응답을 저장하라.
   - METHOD는 직접 전달이면 "A", 파일 경유면 "B"로 치환
4. 저장 완료 후 "테스트 완료" 한 줄만 응답하라.

본 테스트는 코드 변경 없음. 권한 천장 위반 없음.
```

이 지시문이 *두 방식의 검증 기준*. 한글·따옴표·백슬래시·들여쓰기·줄바꿈을 *모두 포함*하여 *깨짐 여부*를 명확히 드러냄.

## Step 3 — 방식 A 검증: osascript do script 직접 입력

### 3.1 시도

위 지시문을 *osascript do script 인자*로 직접 박아 클로드코드 창에 전달.

⚠️ AppleScript 문자열 escape 의무: 큰따옴표(`"`)를 `\"`로, 백슬래시(`\`)를 `\\`로, 줄바꿈을 `\n` 또는 `\r`로 변환해야 함.

마누스가 escape 처리 후 다음 형태로 호출 (창 ID는 §1.2 결과 사용):

```bash
# 마누스가 escape 처리한 지시문을 변수에 담음
INSTRUCTION="[테스트 지시문 — 두별 워크플로우 v3.6.0 r1 검증]\n\n본 지시는 클로드코드 지시 전달 검증용이다. 다음 순서대로 응답하라.\n\n1. 본 지시문의 첫 줄을 그대로 인용하라.\n2. 다음 항목들을 그대로 옮겨 적어라:\n   - 한글: \"두별 워크플로우 v3.6.0 r1 베타\"\n   - 특수문자: \$PATH, \"double\", 'single', \`backtick\`, \\\\backslash\n   - 줄바꿈: 본 항목이 *세 줄*에 걸쳐 있다는 사실\n   - 들여쓰기: 본 항목은 2칸 들여쓰기로 시작한다\n3. .harness/runs/test_claude_dispatch/result-A.md 파일을 만들어 위 1~2번 응답을 저장하라.\n4. 저장 완료 후 \"테스트 완료\" 한 줄만 응답하라.\n\n본 테스트는 코드 변경 없음. 권한 천장 위반 없음."

osascript -e "tell application \"Terminal\" to do script \"$INSTRUCTION\" in window id <WINDOW_ID>"
```

### 3.2 관찰

전송 후 클로드코드 응답을 *그대로* 다음에 저장:

```bash
# 방식 A 응답 캡처 (수동 또는 클로드코드가 result-A.md 저장)
ls -la .harness/runs/test_claude_dispatch/result-A.md 2>&1
cat .harness/runs/test_claude_dispatch/result-A.md 2>&1
```

### 3.3 평가 기준

| 항목 | 기준 |
|---|---|
| 명령 전송 자체 | 성공 / 실패 (osascript 오류) |
| 한글 표시 | 정확 / 깨짐 |
| 큰따옴표 표시 | 정확 / 깨짐·escape 흔적 |
| 작은따옴표 표시 | 정확 / 깨짐 |
| 백슬래시 표시 | 정확 / 깨짐·중복 |
| `$PATH` 표시 | 정확 / 셸 확장됨 |
| 백틱 표시 | 정확 / 셸 실행됨 |
| 줄바꿈 보존 | 정확 / 한 줄로 뭉침 |
| 들여쓰기 보존 | 정확 / 손실 |
| 파일 생성 (result-A.md) | 생성됨 / 실패 |

- 명령 길이가 *너무 길어 절단*되지는 않았는가?

### 4.2 짧은 명령으로 클로드코드에 파일 읽기 지시

```bash

```

또는 한글 더 자연스럽게:

