## task 개요

**목표**: 두별 워크플로우 스킬 9개를 공개 GitHub 저장소로 등록하고, 마누스 본인에 import해서 동작 확인.

**배경**:
- 임시 컨설턴트 클로드가 스킬 9개 (각각 SKILL.md + scripts/ + references/) 설계 완료. `/home/claude/skills-repo/`에 보관 중.
- 33개 파일 (스킬 9개 × 3~4 파일 + README + LICENSE) 완성. r6 매뉴얼·양식 일괄 정정 결과도 반영됨.
- 다음 단계: 공개 GitHub 저장소에 push → 마누스 Settings → Skills → Import from GitHub → 9개 모두 import 성공 여부 검증.

**핵심 불확실성 (마누스가 답해야 할 것)**:
- Manus Skills의 *multi-skill 단일 저장소* import 동작이 1차 출처에 명시되지 않음
- 가능성 3가지:
  - (가) 마누스가 *루트 SKILL.md만* 인식 — 9개 개별 저장소 필요
  - (나) 마누스가 *하위 폴더 자동 탐색* — 우리 구조 그대로 OK
  - (다) *하위 폴더 URL 각각* 입력 → 9번 import 반복

## Step 1 — Manus Skills 1차 출처 재확인

마누스가 직접 확인:

1. https://manus.im/docs/features/skills — Skills 공식 문서
2. https://help.manus.im/en/articles/14753565-how-to-share-and-use-skills-in-manus — GitHub import 절차
3. Manus Settings → Skills → + Add → Import from GitHub *실제 UI* 확인
4. 다음 사항 확정:
   - 단일 저장소에 *여러 스킬* 가능 여부
   - 하위 폴더 자동 탐색 여부
   - 만약 *루트 SKILL.md만 인식*한다면 multi-skill 저장소 우회 방법
   - 검증된 multi-skill 저장소 사례 확인 (예: `abcnuts/manus-skills`, `yuanqi99/manus-skills` 구조 분석)

**산출**: `.harness/runs/<run_id>/manus-skills-import-spec.md`

내용:
- 1차 출처 근거 (URL + 인용)
- multi-skill 저장소 가능 여부 결론
- 가능하면 *권고 구조* (어떤 폴더 구조가 마누스에서 잘 인식되는지)
- 불가능하면 *우회 방법* (각 스킬 별도 저장소? 또는 다른 패턴?)

## Step 3 — GitHub 저장소 생성 + push

Step 2 검증 결과에 따라 분기:

### 분기 A: 우리 구조가 import 가능
1. 공개 GitHub 저장소 생성 (저장소명 [Owner] 결정 — 권고: `dubyeol-workflow-skills`)
2. 33개 파일 push
3. README·LICENSE 검토

### 분기 B: 우리 구조가 import 안 됨
1. Step 1에서 발견한 *권고 구조*로 정정안 작성
2. [Owner] 명시 승인 후 정정 진행
3. 정정 후 GitHub 저장소 생성 + push

### 분기 C: 9개 개별 저장소 필요
1. [Owner] 명시 승인 + 저장소 9개 생성 부담 검토
2. 부담 수용 가능 시 9개 저장소 push
3. 아니면 [Owner] 결정 — 단일 저장소 + 우회 방법 (수동 import 9회 등)

push 절차:
- [Owner]가 저장소 생성 후 *push 권한*을 제공하거나, [Owner]가 직접 push
- 또는 마누스가 가이드 (`git remote add origin`, `git push -u origin main`) 제공

**산출**: GitHub 저장소 URL 또는 9개 저장소 URL 목록

## Step 4 — 마누스 import 검증

GitHub push 완료 후 마누스 본인에서 import 시도:

1. Manus Settings → Skills → + Add → Import from GitHub
2. 저장소 URL 입력 → Import 클릭
3. 결과 확인:
   - 9개 모두 import 성공? 또는 일부?
   - import된 스킬 목록을 `/` 입력해서 확인
   - 각 스킬 `description` 정확히 인식?

**스킬 동작 점검 (간단)**:
- `/01-load-sub-manual` 호출 시 SKILL.md 로드 확인
- scripts/ 실행 권한 확인 (실제 task는 silkroadhub 가동 후 검증)

**산출**: `.harness/runs/<run_id>/manus-import-verification.md`

내용:
- import 시도 결과
- 인식된 스킬 목록 (9개 일치 여부)
- 발견된 문제·차이점
- 권고 사항 (구조 변경 필요 시)
